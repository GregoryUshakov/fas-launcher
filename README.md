# FAS Launcher

Лаунчер сервера проекта FAS для Windows 10/11 x64.

## Скачать

[Скачать последнюю версию](https://github.com/GregoryUshakov/fas-launcher/releases/latest) — выберите файл `FASLauncher-Setup-<версия>.exe`.

Для игры нужны Steam, установленный DayZ и приглашение на закрытый альфа-тест FAS.

## Возможности

- Проверка доступности сервера и получение актуального списка модов.
- Проверка, подписка и обновление модов через Steam Workshop.
- Запуск DayZ через BattlEye с модами FAS и сохранённым игровым никнеймом.
- Просмотр последнего клиентского scriptlog и открытие папки логов.
- Автоматическое обновление лаунчера с проверкой подписи пакета.

.NET и Node.js включены в установщик. Настройки и никнейм сохраняются при обновлении.
